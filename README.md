# Task 28: Outlier Detection

## Overview
This project demonstrates basic outlier detection using a box plot and the Interquartile Range (IQR) method.

## Objective
To visualize a numerical variable and identify potential outliers in a dataset.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset
A sample employee salary dataset containing 10 employees.

## Method
1. Load and explore the dataset.
2. Calculate Q1 and Q3.
3. Calculate the IQR.
4. Determine the lower and upper bounds.
5. Identify potential outliers.
6. Visualize the data using a box plot.

## Results
The salary of ₹150,000 was flagged as a potential outlier because it exceeded the upper IQR boundary.

## Conclusion
Box plots and the IQR method help identify unusual values in numerical data. Each potential outlier should be investigated before deciding whether it should be retained or removed.

- Box plot visualization
- Identified potential outliers
- Explanation of findings
